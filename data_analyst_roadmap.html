Phase 6 — Tableau (Weeks 18–20, Optional but Recommended)

Yes — learn Tableau after Power BI. Many companies (especially MNCs, consulting, US-based firms) still prefer Tableau, and knowing both makes you significantly more hireable.
  • Tableau Public (free version) installation & interface
  • Connecting data sources, basic chart types
  • Calculated fields, Table Calculations, LOD expressions
  • Dashboard actions, parameters, filters
  • Publishing to Tableau Public profile (acts as a public portfolio!)

Resources: YouTube — Tableau official channel, Pavan Lalwani; practice via Tableau Public's "Viz of the Day" gallery for inspiration.

Phase 7 — Advanced Google Sheets (Week 20–21)

  • QUERY — SQL-like querying inside Sheets
  • FILTER / ARRAYFORMULA — dynamic, formula-driven datasets
  • IMPORTRANGE — linking multiple spreadsheets (used heavily in startups)
  • Apps Script — automation (e.g., auto-email reports)
  • Connected Sheets — pulling BigQuery data directly into Sheets

Resource: YouTube "Google Sheets QUERY function," Ben Collins' free blog (bencollins.co.uk) — one of the best free Sheets resources available.

Phase 9 — Business Analytics Concepts (Weeks 21–23)

  • KPI vs OKR — what to measure vs how to align goals
  • Funnel Analysis — conversion drop-off at each stage
  • Cohort Analysis — retention over time by user groups
  • Customer Segmentation — RFM, demographic, behavioral
  • Churn Analysis — predicting and explaining customer loss
  • Sales Analysis — pipeline, region, rep performance
  • Financial Metrics — revenue, margin, CAC, LTV
  • Supply Chain Analytics — inventory turnover, lead time

Resource: YouTube: "Business Analytics" by Alex The Analyst, Luke Barousse — both explain these with real dashboard examples.

Phase 10 — Data Visualization Mastery (Weeks 23–24)

  • Choosing the right chart for the right question (avoid pie chart overuse!)
  • Color theory — using color to highlight, not decorate
  • Executive dashboard design — fewer numbers, more insight
  • Common mistakes: too many colors, 3D charts, cluttered KPIs, no clear hierarchy

Resource: "Storytelling with Data" (free blog + YouTube talks by Cole Nussbaumer Knaflic), Chandoo.org dashboard breakdowns.

Phase 13 — Resume Building

  • Use a clean, single-column ATS-friendly template (avoid tables/graphics that break ATS parsing)
  • Lead each bullet with an action verb + quantified result ("Built a Power BI dashboard reducing report time by 40%")
  • Include a "Projects" section with GitHub links — extremely important for analysts with no job experience
  • Add a "Skills" section grouped by category: Tools, Languages, Concepts
  • Common mistakes: walls of text, no metrics, generic objective statements, listing every tool you've "heard of"

Phase 14 — LinkedIn Optimization

  • Headline: "Data Analyst | SQL • Python • Power BI • Excel | Turning Data into Decisions" (not just "Aspiring Data Analyst")
  • About section: Short story of your journey + 2–3 project highlights + call to action
  • Featured section: Pin your top 3 dashboards/projects with links
  • Networking: Comment thoughtfully on analyst posts, connect with recruiters with a short personalized note
  • Job search: Use LinkedIn's "Open to Work" + set up job alerts for "Data Analyst" + filter by "Entry Level"

Phase 15 — Interview Preparation

  • SQL: Practice 50+ JOIN/window-function questions on StrataScratch/DataLemur
  • Excel: Be ready to explain VLOOKUP vs INDEX/MATCH vs XLOOKUP, pivot table logic live
  • Power BI: Be ready to explain a measure you wrote and why you chose DAX over a calculated column
  • Python: Practice live Pandas data-cleaning challenges (loading messy CSV, fixing nulls/duplicates)
  • HR round: Prepare your project story using the STAR method (Situation, Task, Action, Result)
  • Case studies: Practice "metric dropped, why?" style business case questions out loud

For a question bank: search "Top SQL interview questions GeeksforGeeks," "Power BI interview questions InterviewBit" — both free and extensive.

Common Beginner Mistakes

  • Collecting certificates instead of building projects
  • Skipping SQL practice (it's the #1 most-tested skill in interviews)
  • Dashboards with no business story or insight — just charts
  • Not learning Git, so all work stays invisible to recruiters
  • Applying only after feeling "100% ready" — start applying at 70% ready

How to Stand Out from Other Analysts

  • Publish full case studies (problem → process → insight → business recommendation), not just dashboard screenshots
  • Use real or scraped datasets occasionally instead of only common Kaggle ones everyone uses
  • Show before/after impact numbers wherever possible
  • Be the person in interviews who explains why a metric matters to the business, not just how to calculate it

Internship & Job Application Strategy

  • Apply to 5–10 roles daily once your portfolio has 3+ solid projects
  • Target both "Data Analyst" and adjacent titles: Business Analyst, Reporting Analyst, BI Analyst, MIS Executive
  • Use referrals via LinkedIn networking — far higher response rate than cold applications
  • Track applications in a simple Sheet: company, role, date applied, status, follow-up date
Build something. Ship it. Iterate. Consistency over 6–12 months beats intensity for 2 weeks. Good luck 🚀
